1. Account Creation
Step 1: Visit Azure Website

Navigate to the Azure official website:

https://azure.microsoft.com

Click on:

Start Free
Step 2: Create a Microsoft Account

If you do not already have a Microsoft account:

Click Create one
Enter:
Email address
Password
Country/Region
Accept the terms and conditions
2. Email Verification

Azure sends a verification code to the registered email address.

Steps
Open your email inbox
Locate the verification email
Copy the verification code
Paste the code into the Azure signup page
3. Phone Verification

Azure requires phone verification for security purposes.

Steps
Enter your phone number
Select SMS or voice verification
Enter the OTP code received
4. Credit Card Verification

Azure requires a valid debit or credit card for identity verification.

Important Notes
No charges are made during signup for the free tier
Azure may temporarily authorize a small verification amount
Steps
Enter card details
Enter billing address
Complete verification
5. Azure Portal Login

12. Troubleshooting
Issue: Unable to Verify Phone Number
Solution
Ensure correct country code
Retry after a few minutes
Use SMS instead of voice verification
Issue: Credit Card Rejected
Solution
Verify card details
Ensure international transactions are enabled
Try another card if necessary
Issue: Cannot Access Azure Portal
Solution
Confirm internet connection
Clear browser cache
Use incognito mode
Reset Microsoft account password
Issue: Budget Alert Not Triggering
Solution
Verify budget scope
Ensure notifications are configured properly
Check subscription permissions
